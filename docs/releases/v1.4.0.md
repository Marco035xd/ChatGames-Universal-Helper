**ChatGames Infection Server · Minecraft Java 26.2 · Fabric**

Cada minijuego ahora tiene tiempos independientes para **Fácil**, **Media (Normal)** y **Difícil (Experto)**.

Pulsa **G → Juegos → una categoría** y elige el nivel. Configura un tiempo fijo o un intervalo decimal de 0 a 60 segundos, o deja que use el tiempo base. Por ejemplo, Matemáticas Fácil puede usar 2.1–2.9 s y Experto 20–30 s; Trivia y las otras categorías conservan sus propios ajustes.

- Se usa el nivel que anuncia el servidor, sin deducirlo de la longitud del problema.
- Prioridad: tiempo del nivel → base del minijuego → tiempo general. Sin nivel anunciado se usa la base.
- Los valores anteriores se conservan como base hasta que guardes un intervalo propio para un nivel.
- Comandos con autocompletado: `/cgedit settime math expert random 20s 30s`, `/cgedit settime math` y `/cgedit settime math expert default`. También se aceptan `facil`, `media`, `medio`, `experto` y `dificil`.
- Perfiles, vista previa y deshacer incluyen los nuevos tiempos. Los perfiles anteriores siguen siendo compatibles.
- El intervalo se cuenta desde recibir el reto completo; no se añade espera de agrupación de mensajes. Un envío ya programado conserva su tiempo elegido.

**Nuevo nombre:** ChatGames Universal Helper pasa a **ChatGames Infection Server**. El nombre del JAR cambia; se mantiene el identificador interno para conservar la configuración y evitar instalaciones duplicadas.

**Instalación:** cierra Minecraft, retira el JAR anterior de este mod e instala `chatgames-infection-server-1.4.0.jar`. Conserva `config/chatgames-universal-helper/`, tus perfiles y respuestas. No instales `-sources.jar`.

**Validación:** compilación y 111 pruebas JUnit aprobadas, incluidas las 14 rondas recientes, selección por nivel, herencia, decimales, perfiles, comandos, deduplicación y recuperación ante fallos de guardado. GUI comprobada en un mundo local de Minecraft 26.2: guardado decimal, cancelación y separación de Matemáticas y Trivia. No se probó conectada al servidor remoto Infection.
