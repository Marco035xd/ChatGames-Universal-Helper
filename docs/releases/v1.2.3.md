# ChatGames Universal Helper 1.2.3

Mod de cliente para **Minecraft Java 26.2**, con Fabric.

## Descargar e instalar

1. Descarga **chatgames-universal-helper-1.2.3.jar** de los archivos adjuntos de esta release.
2. Cierra Minecraft y sustituye el JAR anterior en la carpeta `mods`. Deja una sola versión del helper.
3. Conserva `config/chatgames-universal-helper/` para mantener tus preferencias y respuestas aprendidas.
4. Inicia el juego y pulsa **G** para abrir el menú, o escribe `/cgedit gui`.

Requiere **Java 25 o superior**, **Fabric Loader 0.19.5 o superior** y **Fabric API para Minecraft 26.2**. Se compiló con Fabric API `0.161.0+26.2`.

El archivo `chatgames-universal-helper-1.2.3-sources.jar` contiene el código fuente y no se instala en `mods`.

## Incluido en esta versión

- Ajustes individuales de tiempo fijo o intervalo aleatorio por minijuego, con decimales como **2.1–2.9 segundos**.
- Botones **−0.1 / +0.1** para modificar cada límite por décimas y una opción rápida de 2.1 a 2.9 segundos.
- Comandos con punto o coma decimal: `/cgedit settime trivia random 2.1 2.9` o `/cgedit settime trivia random 2,1 2,9`.
- Acceso con **G**, configurable en los controles de Minecraft bajo ChatGames.
- Base actualizada con 15 preguntas de trivia, 57 patrones para completar palabras, 52 anagramas y 19 palabras, extraídos de rondas confirmadas del 2 al 20 de octubre de 2026.
- Contador del próximo minijuego, interfaz privada y conservación de los ajustes al reiniciar.
