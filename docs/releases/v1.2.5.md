# ChatGames Universal Helper 1.2.5

Mod de cliente para **Minecraft Java 26.2**, con Fabric. Añade la cuenta completa hasta el próximo minijuego.

## Contador permanente

- Panel en la parte superior central con **«Nuevo minijuego en 07:58»**, actualizado en minutos y segundos durante toda la espera.
- Mientras se juega una ronda, indica **«Minijuego en curso»**. Cuando alguien responde o la ronda termina, muestra lo que queda hasta el siguiente inicio estimado.
- El contador se sincroniza con cada inicio real y descuenta el tiempo de resolución. Por ejemplo: intervalo 08:01 y respuesta a los 3 segundos → quedan 07:58.
- El intervalo inicial es **08:01**. Se revisaron 191 rondas de noviembre y 176 intervalos consecutivos; los inicios estuvieron separados por 08:00 a 08:03. Es una estimación, ajustable a otros servidores.
- Permite activar o desactivar el panel, elegir vista permanente o solo los últimos diez segundos, cambiar minutos y segundos y controlar notas y volumen.
- Las respuestas automáticas y el contador tienen controles independientes. El contador sigue sincronizándose aunque las respuestas estén en pausa.

## Cómo activarlo

Pulsa **G → Contador → Contador: activado → Vista: permanente → Guardar cambios**.

También puedes utilizar:

```text
/cgedit countdown on
/cgedit countdown view full
/cgedit countdown interval 8 1
```

Al entrar, espera un minijuego real para sincronizarse. Si la estimación vence, espera el siguiente anuncio; no inventa otra ronda. Al desconectarse se borra la referencia.

## Instalación

Cierra Minecraft, sustituye el JAR anterior por **chatgames-universal-helper-1.2.5.jar** y conserva `config/chatgames-universal-helper/`. Deja una sola versión en `mods`.

Requiere **Java 25 o superior**, **Fabric Loader 0.19.5 o superior** y **Fabric API para Minecraft 26.2**. El archivo `*-sources.jar` contiene fuentes y no se instala en `mods`.

El antiguo intervalo predeterminado de 25 minutos pasa a 08:01. Los intervalos distintos del antiguo valor predeterminado, los tiempos de respuesta y las preferencias de activación y sonido se conservan.

## Verificación

82 pruebas JUnit aprobadas, incluidas las 176 mediciones de intervalos, el cálculo desde el resultado, la deduplicación de chat y log, el guardado de minutos/segundos y la migración de configuraciones. La apariencia del panel no se probó manualmente en Minecraft ni se verificó el horario futuro del servidor remoto.
