ChatGames 1.3.0 incorpora un centro de control completo para Minecraft Java 26.2 (Fabric).

- **GUI renovada:** Inicio, Juegos con búsqueda y filtros, Historial, Perfiles y Pruebas.
- **Historial:** últimos 100 retos de esta ejecución, respuesta, espera elegida y tiempo real hasta el envío. No confunde envíos con victorias.
- **Perfiles:** guardar, revisar, aplicar y deshacer la carga; hasta 32 perfiles locales.
- **Laboratorio:** ejemplos y soluciones locales sin enviar mensajes ni consultar IA.
- **G** abre el panel y **H** pausa/reanuda; ambas teclas son reasignables.
- HUD con barra de espera y comandos nuevos: `profile`, `history`, `report`, `hud`, `pause`, `resume`; ayuda pulsable en cuatro páginas.

Se mantienen tus tiempos decimales, juegos pausados, respuestas aprendidas y contador de 08:01. Sigue sin añadirse la antigua espera de agrupación.

**Instalación:** cierra Minecraft, sustituye el JAR anterior por `chatgames-universal-helper-1.3.0.jar` y conserva la carpeta de configuración. El archivo `-sources.jar` es para desarrolladores.

**Requisitos:** Minecraft 26.2, Java 25+, Fabric Loader 0.19.5+ y Fabric API.

**Validación:** 93 pruebas JUnit aprobadas. Se revisaron la interfaz y los flujos principales en un mundo local de Minecraft 26.2, incluida una respuesta real, su historial y el contador. No se probó en el servidor remoto Infection.
