# ChatGames Universal Helper 1.2.4

Actualización para **Minecraft Java 26.2**, con Fabric, centrada en los tiempos de respuesta.

## Cambios

- **Eliminada la espera adicional de agrupación de mensajes** de 350 ms o hasta 3 segundos. Un reto completo se procesa al llegar, sin esperar a que el chat quede en silencio.
- El mod recibe los retos directamente del chat en vivo y conserva la lectura de registros como respaldo, evitando duplicados.
- **El tiempo configurado se cuenta desde que el cliente recibe el reto completo**. Por ejemplo, 2.1–2.9 s programa el envío dentro de ese intervalo desde la recepción, incluyendo el tiempo de cálculo. Si el cálculo tarda más, se envía en cuanto termina.
- Se mantienen las preguntas partidas en varias líneas y las ecuaciones con símbolos; se procesan en cuanto tienen el texto necesario.
- Las conversaciones de jugadores no se mezclan con los retos.
- Se conservan los intervalos personales, las respuestas aprendidas, los juegos pausados y el acceso con **G**.

El ping, los retrasos del servidor, la carga del cliente o una consulta a la IA opcional pueden afectar al tiempo real de recepción del servidor. El mod no garantiza ganar cada ronda.

## Instalación

1. Descarga `chatgames-universal-helper-1.2.4.jar` de los archivos adjuntos.
2. Cierra Minecraft y reemplaza el JAR anterior en `mods`, dejando una sola versión.
3. Conserva `config/chatgames-universal-helper/` para mantener tus ajustes y respuestas.
4. Inicia Minecraft. Pulsa **G** o utiliza `/cgedit gui`.

Requiere **Java 25 o superior**, **Fabric Loader 0.19.5 o superior** y **Fabric API para Minecraft 26.2**.

El archivo `*-sources.jar` contiene fuentes y no se instala en `mods`.

## Verificación

75 pruebas JUnit aprobadas, incluidas pruebas de detección inmediata sin forzar el vaciado de mensajes, plazos configurados, tiempo de cola incluido en el intervalo, preguntas partidas, ecuaciones y deduplicación de las 328 rondas de octubre. El cambio no se probó en el servidor remoto de Minecraft.
